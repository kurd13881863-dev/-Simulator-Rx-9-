# Simulator Rx-9

A mobile-friendly, installable web app for an interactive 3D rotary engine simulation.

## Publish on GitHub Pages
1. Create a new repository on GitHub named `simulator-rx-9`.
2. Extract this ZIP file. Upload **the contents** of this folder (especially `index.html`, `script.js`, `style.css`, `manifest.webmanifest`, and `icons/`) to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**. Select `main` and `/ (root)`, then press **Save**.
5. Wait for the Pages deployment and open the published link.

The web app can be added to a phone's home screen from its browser menu. Three.js is loaded from the CDN, so the first load needs an internet connection.
